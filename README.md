Computer scientists solve real-world problems through technological means. Their job is to find ways in which we can improve societal functions in efficient ways. As a computer scientist, I approach a problem by considering who I am trying to benefit and what makes sense for the particular scenario. However, even though complexity wouldn't be necessary, it is still important that my algorithm completes the specified tasks. 

My ethical responsibilities both to the end user and the organization include making code that is secure, performs the tasks outlined, and leaves no room for exploitation.
